Datenschutzerklärung

Stand: 21.11.2026. Diese Anwendung („rclone“) ist ein privates Werkzeug, das ausschließlich vom Betreiber selbst genutzt wird.

Welche Daten werden verwendet?

Die Anwendung greift nach Zustimmung des Betreibers auf dessen eigenes Google Drive zu (Lesen, Schreiben, Löschen von Dateien und Ordnern). Sie verarbeitet nur diese Daten und nur zu dem Zweck, sie auf dem eigenen Server als Ordner bereitzustellen und zu sichern.

Speicherung und Weitergabe

Die Zugangsdaten und der Zwischenspeicher liegen ausschließlich auf einem privaten Server im Haushalt des Betreibers. Es erfolgt keine Weitergabe, kein Verkauf und keine Veröffentlichung von Daten an Dritte. Es gibt keine weiteren Nutzer.

Löschung

Der Betreiber kann den Zugriff jederzeit unter myaccount.google.com/permissions widerrufen und die lokal gespeicherten Daten löschen.

Verantwortlicher

Betreiber dieses privaten Werkzeugs (Privatperson). Kontakt über das GitHub-Profil, unter dem diese Seite veröffentlicht ist.

Privacy policy

Last updated: 21 November 2026. This application ("rclone") is a private tool used exclusively by its owner.

Data used

With the owner's consent, the application accesses the owner's own Google Drive (read, write and delete files and folders). It processes only this data, solely to provide it as a folder on the owner's own server and to back it up.

Storage and sharing

Credentials and cache are stored only on a private server in the owner's household. Data is not shared, sold or published. There are no other users.

Deletion

The owner can revoke access at any time at myaccount.google.com/permissions and delete the locally stored data.

Controller

The operator of this private tool (an individual). Contact via the GitHub profile under which this page is published.
